# Dashboard data: SYNTHETIC

SYNTHETIC DATA - generated by sim/gen_city_data.py. Invented road grid, invented schools/stops ('Synthetic School A', 'Synthetic Stop 1', ...) and invented counts around Ajman's centre coordinates. Not real places, not measurements. Urgent-alert rate taken from the simulated HearMe Monte Carlo (docs/results/results.json).

- `synthetic_counts.csv`: cell_id, lat, lon, hour, fast_passes, urgent_alerts — one row per road cell and hour, summed over a synthetic 30-day month. (No comment line inside the CSV so standard CSV readers, including `apps/dashboard/api/seed.py`, can parse it.)
- `synthetic_pois.json`: invented schools and bus stops.

Urgent alerts are drawn as Binomial(fast_passes, 0.9671); that rate is the simulated share of fast passes within 5 m that triggered an URGENT alert in the HearMe-GPS Monte Carlo condition.

Regenerate: `python sim/montecarlo.py` then `python sim/gen_city_data.py`.
